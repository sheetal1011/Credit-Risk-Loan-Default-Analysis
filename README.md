# Credit Risk & Loan Default Analysis

🎯 Objectives & Approach
1. **Executive Summary & Baseline Metrics** — KPI cards tracking total applicants, capital disbursed, and overall default rate
2. **Impact of Age on Default Probability** — Line chart analyzing default rate trends across applicant age
3. **Default Risk by Loan Purpose** — Column chart comparing default rates across loan intent categories
4. **Home Ownership as a Risk Factor** — Donut chart breaking down default proportions by housing status
5. **Risk Segmentation by Loan Grade** — Interactive slicer (A–G) for grade-specific analysis
6. **Loan-to-Income Ratio Impact** — Area chart identifying the DTI threshold where risk accelerates

🛠️ Tools Used
- **SQL** — Data cleaning, aggregation, and exploratory analysis
- **Power BI** — Interactive dashboard and data visualization
